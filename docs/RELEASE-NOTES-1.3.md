# Compás 1.3

The English and Spanish 1.3 packages are byte-for-byte promotions of the
qualified 1.3-rc.4 candidate.

- **38 groove studies.** Nine new source-labelled accompaniment studies cover
  Mexican Sureste, four Pará studies, two north-coast Peru studies, a Costa
  Chica 6/8 accompaniment and a 12/8 bell/block study. Source notes distinguish
  published reductions, authored support, proxy voices and work still awaiting
  local musician review.
- **6/8 and 12/8.** Compound studies display dotted-quarter pulse BPM while
  outgoing MIDI clock remains 24 PPQN for quarter notes.
- **Kumbia balance.** K4 is LEVEL / NIVEL, 0–100. OCT−/+ adjusts the sample
  CLOCK / RELOJ in Hz. Mixer OCT−/+ reaches the same kit level.
- **Full digital output conversion.** The final Q15-to-24-bit multiplier is
  restored from 128 to 256, a 6.02 dB digital gain correction. This does not
  claim a measured analogue voltage or guarantee a particular PA level.
- **Persistent shows.** The CPS6 journal keeps supported shows, user rhythms
  and Kumbia controls across power-off. Firmware updates clear it, so export
  the show with Big Beat Editor before installing.
- **Editor build 13.** The foreground USB adapter advertises all 38 studies and
  retains transactional SET, CRC-checked snapshots and transport control.

Both packages contain the same bilingual instrument; the selected download
only changes the first-boot language. Use GLO then ALGORITHM to change language
later. The firmware identity remains `FM-1_92210003`.

The qualification boundary is explicit in `docs/QUALIFICATION-1.3.md`.
Physical English and Spanish package, transport, editor and MIDI-clock checks
passed. The exact 1.3-to-stock-V15 cycle, panel save/power-cycle gestures,
analogue measurement and regional musician review remain follow-up checks.
