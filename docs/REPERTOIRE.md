# Compás repertoire sources

Compás includes original rhythm studies and arrangements of the editions
identified below. Edition-specific rights and source details are retained in
the JSON ledgers in `repertoire/`. See [LICENSING.md](../LICENSING.md) for
the software, sample-bank and openly licensed score notices.
