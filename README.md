# Compas 1.1

Compas turns the M-VAVE FM-1 into a Latin rhythm section: cumbia, salsa,
merengue and bolero, with English and Spanish builds.

- [Install Compas](https://thebigbeat.app/compas/install/)
- [Play in the browser](https://thebigbeat.app/compas/play/)
- [Compas 1.1 release](https://github.com/TexasRADIO/compas-firmware/releases/tag/compas-v1.1)

Compas 1.1 has been installed and run on physical M-VAVE FM-1 hardware. The
release packages use the updater identity `FM-1_92210003` and the standard BB1
loader.

The complete release source is in this repository. Build instructions are in
[BUILDING.md](BUILDING.md); licences and credits are in
[LICENSING.md](LICENSING.md).
